```text
COMMUNICATION GRAPH  →  SOFTWARE GRAPH
```

## Commands

```bash
./scripts/render.sh conways-law
./scripts/render.sh conways-law -qh
./scripts/export_html.sh conways-law
./scripts/present.sh conways-law
```

`present.sh` serves `dist/` at **http://127.0.0.1:8000/**. Notes: [`SPEAKER_NOTES.md`](SPEAKER_NOTES.md). Press `S` for Reveal speaker view.
